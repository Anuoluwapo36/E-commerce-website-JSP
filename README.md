E-commerce Website (JSP & MySQL)
This project is a full-featured E-commerce platform built using JavaServer Pages (JSP) and MySQL. It supports both seller and buyer roles, enabling seamless online trading and management of products, orders, and sales.

Features
For Buyers:

Browse products and categories
Add items to cart
Track orders
Make payments
Update user information
For Sellers:

Perform CRUD operations on products
Track order and sales history
Access sales reports
Technologies Used
Backend: JSP (JavaServer Pages)
Database: MySQL
Frontend: HTML, CSS, JavaScript (as needed)
Setup Instructions
Clone the repository

bash
git clone https://github.com/Anuoluwapo36/E-commerce-website-JSP.git
Database Setup

Install MySQL and create a database for the project.
Import the provided SQL schema from the /database folder.
Update database connection details in the project’s configuration files.
Deploy JSP Application

Use a Java application server (such as Apache Tomcat).
Deploy the project files to your server’s webapps directory.
Configure Application

Ensure database credentials and paths are correctly set.
Start the application server and access the application via your browser.
Usage
Register as a buyer or seller.
Buyers can search, browse, add products to cart, track their orders, and update their profile.
Sellers can add new products, edit or delete listings, view order notifications, and generate sales reports.
